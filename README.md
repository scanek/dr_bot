# Telegram Birthday Bot 🎂

Бот для отслеживания дней рождения сотрудников/друзей и автоматической отправки поздравлений в Telegram-канал.

## Особенности
- 🕒 Автоматическая проверка дней рождения каждый день в 08:00 (по МСК).
- 📝 Удобное добавление, изменение и удаление дат прямо в чате с ботом.
- 🔒 Безопасность: управлять базой данных могут только авторизованные администраторы (проверка по Telegram ID).
- 🐳 Легкий деплой в один клик через Docker.
- 💾 Сохранение данных в JSON (монтируется как том в Docker).

## Установка и запуск (Docker)

### 1. Клонирование репозитория
```bash
git clone https://github.com/scanek/dr_bot.git
cd dr_bot
```

### 2. Настройка окружения
Скопируйте пример файла конфигурации:
```bash
cp .env.example .env
```
Затем откройте файл `.env` в любом текстовом редакторе и заполните его своими данными (токен, ID канала и ваш личный Telegram ID).

### 3. Запуск
Убедитесь, что у вас установлен Docker и Docker Compose. Выполните команду в корневой папке проекта:
```bash
docker compose up -d --build
```
Для остановки бота:
```bash
docker compose down
```

## Доступные команды
*(Работают только для пользователей из списка `ADMIN_IDS`)*
- `/start` - Вызов главного меню.
- `/add_birthday` - Добавить новый день рождения (формат `Имя Фамилия ДД-ММ`).
- `/view_birthdays` - Показать полный список всех записей.
- `/edit_birthday` - Изменить дату уже существующей записи.
- `/delete_birthday` - Удалить запись по имени.
- `/check_birthdays` - Ручной запуск проверки (бот сразу отправит поздравления тем, у кого сегодня праздник, удобно для тестирования).
